طريقة النشر (مطلوب HTTPS ليظهر خيار التثبيت):
1) ارفع كل محتويات هذا المجلد إلى نفس المسار على استضافة HTTPS (Firebase Hosting / Netlify / GitHub Pages / Cloudflare Pages).
2) افتح الرابط:
   - Android/Chrome وWindows/Mac (Chrome/Edge): زر «⬇ تثبيت» أو أيقونة التثبيت في شريط العنوان.
   - iPhone/iPad: Safari ← مشاركة ← «إضافة إلى الشاشة الرئيسية».
لتغيير الأيقونة لاحقاً: استبدل الملفات داخل مجلد icons بنفس الأسماء والأحجام، ثم ارفع نسخة جديدة وغيّر VERSION في service-worker.js.

العمل دون اتصال (v1.0.3):
- افتح التطبيق مرة واحدة مع الإنترنت وسجّل الدخول ليُحفظ المخزون والمؤسسات والصفقات على الجهاز.
- بعدها يمكن الاستلام والتوزيع والإلغاء والجرد دون إنترنت؛ تظهر شارة «عمليات محفوظة على الجهاز» وتُرسَل تلقائياً عند عودة الاتصال.
- تنبيهات: لا تمسح بيانات المتصفح ولا تحذف التطبيق قبل اكتمال المزامنة. إذا عمل جهازان دون اتصال في الوقت نفسه فقد يتكرر رقم وصل تلقائي، وقد يظهر رصيد سالب عند التعارض (يظهر تنبيه بعد المزامنة).
- أول مرة بلا اتصال إطلاقاً: لن تظهر البيانات ولا يمكن الدخول.

استيراد Excel (v1.0.4): الأدوات ← استيراد Excel ← «تحميل النموذج الكامل» ثم املأ الأوراق (المواد، المؤسسات، المفتشون، المصالح الداخلية) واستورد الملف دفعة واحدة. الإدخال اليدوي والاستيراد لكل قائمة على حدة ما زالا يعملان.

الحسابات والصلاحيات (v1.0.5) — خطوات الإعداد بالترتيب:
1) Firebase Console ← Authentication ← Sign-in method ← فعّل «Email/Password».
2) ارفع ملفات التطبيق (هذا المجلد) على الاستضافة.
3) افتح التطبيق ← «أول استعمال؟ إنشاء حساب المدير» ← أنشئ حساب المدير.
4) الأدوات ← المستخدمون ← أضف بقية المستخدمين وحدّد دور كل واحد (مدير / مسؤول المخزون / اطلاع فقط).
5) أخيراً: Firestore Database ← Rules ← الصق محتوى الملف firestore.rules ← Publish. قبل هذه الخطوة تبقى البيانات غير محمية في الخادم.
6) يمكنك حذف الوثيقة القديمة settings/access (كلمة المرور القديمة) من لوحة Firebase.
ملاحظات: الحسابات باسم مستخدم لا تدعم إعادة التعيين بالبريد (عند النسيان يعطّلها المدير وينشئ اسماً جديداً)؛ استعمل بريداً حقيقياً إن أردت هذه الميزة. لا يمكن حذف حساب الدخول من التطبيق، بل تعطيله.
